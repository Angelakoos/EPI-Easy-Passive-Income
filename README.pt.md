## Como Instalar

A seguir estão os passos mais simples para você começar a ganhar dinheiro compartilhando sua conexão.

> **Observação Importante**: Ao alugar seu VPS (por exemplo, na IONOS), vá ao **Painel de Controle** e abra o **firewall** para **todas as portas** (ou só as que precisar). Como não há nada crítico nesse servidor, abrir tudo facilita a configuração.

### 1. Preparar o Sistema

Copie e cole este bloco de comandos para:
1. **Atualizar e otimizar** o sistema,  
2. **Instalar pacotes básicos** (incluindo `nano` para edição de arquivos),
3. **Instalar o Docker**,  
4. **Instalar o Watchtower**,  
5. **Configurar um cron mensal** (dia 1, às 4h da manhã) para manutenção,  
6. **Fazer limpeza** do sistema.

```bash
echo "[INFO] Atualizando e otimizando o sistema..."
apt update && apt upgrade -y
apt install -y curl wget htop ufw git zip unzip nano

echo "[INFO] Instalando Docker..."
apt install -y apt-transport-https ca-certificates software-properties-common
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | apt-key add -
add-apt-repository -y "deb [arch=amd64] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable"
apt update && apt install -y docker-ce
systemctl start docker
systemctl enable docker

echo "[INFO] Instalando Watchtower (atualizações automáticas dos contêineres)..."
docker run -d \
  --name watchtower \
  --restart=always \
  -v /var/run/docker.sock:/var/run/docker.sock \
  containrrr/watchtower \
  --cleanup \
  --revive-stopped \
  --include-stopped \
  --include-restarting \
  --interval 3600 \
  --stop-timeout 30s

echo "[INFO] Configurando tarefa cron mensal (dia 1, às 4h)..."
(crontab -l ; echo "0 4 1 * * apt update && apt upgrade -y && apt install --only-upgrade -y docker-ce && apt update && apt install myst -y && (reboot || sleep 30 && reboot -f)") | sort - | uniq - | crontab -

echo "[INFO] Limpeza final..."
apt autoremove -y && apt autoclean -y
```

> - **Watchtower** verifica atualizações de contêineres a cada hora.  
> - O **cron** roda **no dia 1 de cada mês, às 04:00** (horário do sistema).  
> - O VPS reinicia após atualizar, garantindo que tudo fique em dia.

#### 2.9 ByteLixir (Proxy)

[**Clique aqui para se registrar com bônus!**](https://bytelixir.com/r/NPONRRIEOSLD)

- Você precisará do **Dante** como proxy SOCKS5.  
- Depois, no site do ByteLixir, adicione `socks5://USER:PASS@PUBLIC_IP:15000`.

**Passo A: Criar script com `nano`:**

```bash
nano /root/dante_bytelixir.sh
```

Cole isto:

```bash
#!/bin/bash
echo "[INFO] Instalando Dante para ByteLixir..."
apt update && apt install -y dante-server

USER="YOUR_PROXY_USER"
PASSWORD="YOUR_PROXY_PASSWORD"
PORT="15000"
CONFIG_FILE="/etc/danted.conf"

INTERFACE=$(ip route | grep default | awk '{print $5}' | head -n 1)
if [ -z "$INTERFACE" ]; then
    echo "Não foi possível detectar a interface de rede. Configure 'external' manualmente em $CONFIG_FILE."
    exit 1
fi

cat > $CONFIG_FILE <<EOL
logoutput: syslog
user.privileged: root
user.unprivileged: nobody

internal: 0.0.0.0 port=$PORT
external: $INTERFACE

socksmethod: username

client pass {
    from: 0.0.0.0/0 to: 0.0.0.0/0
}

socks pass {
    from: 0.0.0.0/0 to: 0.0.0.0/0
}
EOL

useradd -r -s /bin/false \$USER
echo "\$USER:\$PASSWORD" | chpasswd

mkdir -p /etc/systemd/system/danted.service.d
cat <<EOC > /etc/systemd/system/danted.service.d/delay.conf
[Service]
ExecStartPre=/bin/sleep 10
Restart=always
RestartSec=10
EOC

systemctl daemon-reload
systemctl restart danted
systemctl status danted --no-pager
netstat -tuln | grep \$PORT

echo "[INFO] Dante configurado na porta \$PORT com usuário '\$USER' e senha '\$PASSWORD'"
```

Salve e feche (`Ctrl + O`, `Enter`, depois `Ctrl + X`).

**Passo B: Dar permissão e executar o script:**

```bash
chmod +x /root/dante_bytelixir.sh
bash /root/dante_bytelixir.sh
```
> Substitua `YOUR_PROXY_USER` e `YOUR_PROXY_PASSWORD` no script.
