## Como Instalar

Abaixo estão os passos mais simples para começar a ganhar dinheiro compartilhando sua conexão de internet.

> **Observação Importante**: Ao contratar seu VPS (por exemplo, na IONOS), entre no **Painel de Controle** e configure o **firewall** para **abrir todas as portas** (ou apenas as necessárias). Como não há nada crítico no servidor, abrir tudo facilita a configuração.

### 1. Preparar o Sistema

Copie e cole este bloco de comandos para:
1. **Atualizar e otimizar** o sistema,  
2. **Instalar pacotes básicos** (incluindo `nano` para editar arquivos),
3. **Instalar o Docker**,  
4. **Instalar o Watchtower**,  
5. **Configurar um cron mensal** (dia 1 às 4 AM) para manutenção,  
6. **Limpar** o sistema.

```bash
echo "[INFO] Atualizando e otimizando o sistema..."
apt update && apt upgrade -y
apt install -y curl wget htop ufw git zip unzip nano

echo "[INFO] Instalando Docker..."
apt install -y apt-transport-https ca-certificates software-properties-common
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | apt-key add -
add-apt-repository -y "deb [arch=amd64] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable"
apt update && apt install -y docker-ce
systemctl start docker
systemctl enable docker

echo "[INFO] Instalando Watchtower (atualizações automáticas de containers)..."
docker run -d \
  --name watchtower \
  --restart=always \
  -v /var/run/docker.sock:/var/run/docker.sock \
  containrrr/watchtower \
  --cleanup \
  --revive-stopped \
  --include-stopped \
  --include-restarting \
  --interval 3600 \
  --stop-timeout 30s

echo "[INFO] Configurando cron mensal (dia 1 às 4 AM)..."
(crontab -l ; echo "0 4 1 * * apt update && apt upgrade -y && apt install --only-upgrade -y docker-ce && apt update && apt install myst -y && (reboot || sleep 30 && reboot -f)") | sort - | uniq - | crontab -

echo "[INFO] Limpeza final..."
apt autoremove -y && apt autoclean -y
```

> - **Watchtower** verifica atualizações de containers a cada hora.  
> - O **cron** roda todo **dia 1 do mês às 04:00** (horário do sistema).  
> - O VPS será reiniciado após a atualização, mantendo tudo atualizado.
