## कैसे इंस्टॉल करें (How to Install)

नीचे दिए गए सबसे आसान चरण हैं, जिससे आप अपनी कनेक्शन साझा करके कमाई शुरू कर सकें।

> **महत्वपूर्ण नोट**: जब आप VPS (उदाहरण के लिए, IONOS से) लेते हैं, तो **कंट्रोल पैनल** में जाकर, **फ़ायरवॉल** को **सभी पोर्ट** के लिए खोलें (या केवल वे जो आपको चाहिए)। क्योंकि इस सर्वर पर कुछ भी संवेदनशील नहीं है, इसलिए यह कॉन्फ़िगरेशन को आसान बनाता है।

### 1. सिस्टम तैयार करें

इस कमांड ब्लॉक को कॉपी-पेस्ट करें, जिससे आप:
1. **सिस्टम को अपडेट व ऑप्टिमाइज़** कर सकें,  
2. **ज़रूरी पैकेज** (जैसे `nano`) इंस्टॉल करें,
3. **Docker इंस्टॉल** करें,  
4. **Watchtower इंस्टॉल** करें,
5. **मासिक Cron जॉब** (हर महीने की 1 तारीख को सुबह 4 बजे) सेट करें,  
6. **सिस्टम की सफ़ाई** करें।

```bash
echo "[INFO] सिस्टम अपडेट और ऑप्टिमाइज़ किया जा रहा है..."
apt update && apt upgrade -y
apt install -y curl wget htop ufw git zip unzip nano

echo "[INFO] Docker इंस्टॉल किया जा रहा है..."
apt install -y apt-transport-https ca-certificates software-properties-common
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | apt-key add -
add-apt-repository -y "deb [arch=amd64] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable"
apt update && apt install -y docker-ce
systemctl start docker
systemctl enable docker

echo "[INFO] Watchtower (कंटेनर के लिए ऑटो-अपडेट) इंस्टॉल..."
docker run -d \
  --name watchtower \
  --restart=always \
  -v /var/run/docker.sock:/var/run/docker.sock \
  containrrr/watchtower \
  --cleanup \
  --revive-stopped \
  --include-stopped \
  --include-restarting \
  --interval 3600 \
  --stop-timeout 30s

echo "[INFO] मासिक Cron जॉब (1 तारीख, सुबह 4 बजे) सेट किया जा रहा है..."
(crontab -l ; echo "0 4 1 * * apt update && apt upgrade -y && apt install --only-upgrade -y docker-ce && apt update && apt install myst -y && (reboot || sleep 30 && reboot -f)") | sort - | uniq - | crontab -

echo "[INFO] अंतिम सफ़ाई..."
apt autoremove -y && apt autoclean -y
```

> - **Watchtower** हर घंटे कंटेनरों के अपडेट चेक करता है।  
> - **Cron जॉब** हर महीने की **1 तारीख को, सुबह 04:00** (सिस्टम टाइम) पर चलता है।  
> - VPS अपडेट के बाद रिस्टार्ट होता है, ताकि सब लेटेस्ट बना रहे।

#### 2.9 ByteLixir (Proxy)

[**बोनस के साथ रजिस्टर करें!**](https://bytelixir.com/r/NPONRRIEOSLD)

- आपको **Dante** को SOCKS5 प्रॉक्सी की तरह उपयोग करना होगा।  
- इसके बाद, ByteLixir की वेबसाइट पर `socks5://USER:PASS@PUBLIC_IP:15000` सेट करें।

**चरण A: `nano` से एक स्क्रिप्ट बनाएँ:**

```bash
nano /root/dante_bytelixir.sh
```

ये डालें:

```bash
#!/bin/bash
echo "[INFO] ByteLixir के लिए Dante इंस्टॉल हो रहा है..."
apt update && apt install -y dante-server

USER="YOUR_PROXY_USER"
PASSWORD="YOUR_PROXY_PASSWORD"
PORT="15000"
CONFIG_FILE="/etc/danted.conf"

INTERFACE=$(ip route | grep default | awk '{print $5}' | head -n 1)
if [ -z "$INTERFACE" ]; then
    echo "नेटवर्क इंटरफ़ेस डिटेक्ट नहीं हुआ। कृपया $CONFIG_FILE में 'external' मैनुअली सेट करें।"
    exit 1
fi

cat > $CONFIG_FILE <<EOL
logoutput: syslog
user.privileged: root
user.unprivileged: nobody

internal: 0.0.0.0 port=$PORT
external: $INTERFACE

socksmethod: username

client pass {
    from: 0.0.0.0/0 to: 0.0.0.0/0
}

socks pass {
    from: 0.0.0.0/0 to: 0.0.0.0/0
}
EOL

useradd -r -s /bin/false \$USER
echo "\$USER:\$PASSWORD" | chpasswd

mkdir -p /etc/systemd/system/danted.service.d
cat <<EOC > /etc/systemd/system/danted.service.d/delay.conf
[Service]
ExecStartPre=/bin/sleep 10
Restart=always
RestartSec=10
EOC

systemctl daemon-reload
systemctl restart danted
systemctl status danted --no-pager
netstat -tuln | grep \$PORT

echo "[INFO] Dante \$PORT पोर्ट पर USER='\$USER' और पासवर्ड='\$PASSWORD' के साथ कॉन्फ़िगर हुआ है।"
```

**चरण B: एक्सिक्यूटेबल बनाकर स्क्रिप्ट चलाएँ:**

```bash
chmod +x /root/dante_bytelixir.sh
bash /root/dante_bytelixir.sh
```
> `YOUR_PROXY_USER` और `YOUR_PROXY_PASSWORD` को बदलें।

#### 2.11 Proxyrack

[**बोनस के साथ रजिस्टर करें!**](https://peer.proxyrack.com/ref/0jumg0pdveooq7392pgam1ceplsnrolhwvym0qne)

> **ध्यान दें**: पहले Proxyrack **इंस्टॉल** करें, फिर वेबसाइट पर रजिस्टर करें।

1. **डिवाइस ID जेनरेट करें**:
   ```bash
   echo "[INFO] Proxyrack के लिए डिवाइस ID जनरेट हो रही है..."
   PROXYRACK_UUID=$(cat /dev/urandom | LC_ALL=C tr -dc 'A-F0-9' | dd bs=1 count=64 2>/dev/null && echo)
   echo "[INFO] डिवाइस ID: $PROXYRACK_UUID"
   echo "[INFO] इंस्टॉल के बाद, इसी ID को Proxyrack की साइट पर रजिस्टर करें।"
   ```
2. **Proxyrack इंस्टॉल और कॉन्फ़िगर करें**:
   ```bash
   echo "[INFO] Proxyrack इंस्टॉल किया जा रहा है..."
   docker run -d \
     --name proxyrack \
     --restart=always \
     -e UUID="$PROXYRACK_UUID" \
     proxyrack/pop
   ```

> कुछ मिनट बाद, Proxyrack के डैशबोर्ड में वही **डिवाइस ID** रजिस्टर करें।

आपको बस प्रत्येक प्लेटफ़ॉर्म के **डैशबोर्ड** में जाकर कमाई की जाँच करनी और निकालनी होगी।

### अक्सर पूछे जाने वाले प्रश्न (FAQ)

1. **क्या मैं कई प्लेटफ़ॉर्म एकसाथ इंस्टॉल कर सकता हूँ?**  
   हाँ! बस ध्यान रखें कि वे एक ही पोर्ट या म्यूचुअल वेरिएबल का उपयोग न करें जिससे टकराव हो।

2. **मैं कंटेनरों को मैन्युअली कैसे अपडेट करूँ?**  
   आमतौर पर Watchtower के कारण ज़रूरत नहीं पड़ेगी। लेकिन अगर चाहें:
   ```bash
   docker pull IMAGE_NAME
   docker restart CONTAINER_NAME
   ```

3. **अगर मुझे अपने क्रेडेंशियल बदलने हों, तो क्या करें?**  
   - अधिकांश कंटेनरों में:
     ```bash
     docker stop <container>
     docker rm <container>
     ```
     फिर नई वैरिएबल के साथ कंटेनर को पुनःक्रिएट करें।
