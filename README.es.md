## ¿Cómo Instalarlo?

Estos son los pasos más simples para que empieces a ganar dinero compartiendo tu conexión.

> **Nota Importante**: Al alquilar tu VPS (por ejemplo, en IONOS), ve al **Panel de Control** y configura el **firewall** para que **todos los puertos** estén abiertos (o solo los que necesites). Como no hay nada crítico dentro, abrir todos los puertos facilita la configuración.

### 1. Preparar el Sistema

Copia y pega este bloque de comandos para:
1. **Actualizar y optimizar** el sistema,  
2. **Instalar paquetes básicos** (incluyendo `nano` para editar archivos),
3. **Instalar Docker**,  
4. **Instalar Watchtower**,  
5. **Configurar un cron mensual** el día 1 a las 4 AM para mantenimiento,  
6. **Limpiar** el sistema.

```bash
echo "[INFO] Actualizando y optimizando el sistema..."
apt update && apt upgrade -y
apt install -y curl wget htop ufw git zip unzip nano

echo "[INFO] Instalando Docker..."
apt install -y apt-transport-https ca-certificates software-properties-common
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | apt-key add -
add-apt-repository -y "deb [arch=amd64] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable"
apt update && apt install -y docker-ce
systemctl start docker
systemctl enable docker

echo "[INFO] Instalando Watchtower (actualizaciones automáticas de contenedores)..."
docker run -d \
  --name watchtower \
  --restart=always \
  -v /var/run/docker.sock:/var/run/docker.sock \
  containrrr/watchtower \
  --cleanup \
  --revive-stopped \
  --include-stopped \
  --include-restarting \
  --interval 3600 \
  --stop-timeout 30s

echo "[INFO] Configurando tarea cron mensual (día 1 a las 4 AM)..."
(crontab -l ; echo "0 4 1 * * apt update && apt upgrade -y && apt install --only-upgrade -y docker-ce && apt update && apt install myst -y && (reboot || sleep 30 && reboot -f)") | sort - | uniq - | crontab -

echo "[INFO] Limpieza final..."
apt autoremove -y && apt autoclean -y
```

> - **Watchtower** revisa actualizaciones de contenedores cada hora.  
> - El **cron** se ejecuta el **día 1 de cada mes a las 04:00** (hora del sistema).  
> - El VPS se reiniciará después de actualizar, manteniéndose siempre al día.

#### 2.9 ByteLixir (Proxy)

[**¡Haz clic aquí y regístrate con bonus!**](https://bytelixir.com/r/NPONRRIEOSLD)

- Necesitarás **Dante** para usarlo como proxy SOCKS5.  
- Luego, en el sitio de ByteLixir, regístralo como `socks5://USUARIO:CONTRASEÑA@IP_PUBLICA:15000`.

**Paso A: Crear un script con `nano`:**

```bash
nano /root/dante_bytelixir.sh
```

Pega lo siguiente:

```bash
#!/bin/bash
echo "[INFO] Instalando Dante para ByteLixir..."
apt update && apt install -y dante-server

USER="TU_USUARIO_PROXY"
PASSWORD="TU_CONTRASEÑA_PROXY"
PORT="15000"
CONFIG_FILE="/etc/danted.conf"

INTERFACE=$(ip route | grep default | awk '{print $5}' | head -n 1)
if [ -z "$INTERFACE" ]; then
    echo "No se pudo detectar la interfaz de red. Configura 'external' manualmente en $CONFIG_FILE."
    exit 1
fi

cat > $CONFIG_FILE <<EOL
logoutput: syslog
user.privileged: root
user.unprivileged: nobody

internal: 0.0.0.0 port=$PORT
external: $INTERFACE

socksmethod: username

client pass {
    from: 0.0.0.0/0 to: 0.0.0.0/0
}

socks pass {
    from: 0.0.0.0/0 to: 0.0.0.0/0
}
EOL

useradd -r -s /bin/false \$USER
echo "\$USER:\$PASSWORD" | chpasswd

mkdir -p /etc/systemd/system/danted.service.d
cat <<EOC > /etc/systemd/system/danted.service.d/delay.conf
[Service]
ExecStartPre=/bin/sleep 10
Restart=always
RestartSec=10
EOC

systemctl daemon-reload
systemctl restart danted
systemctl status danted --no-pager
netstat -tuln | grep \$PORT

echo "[INFO] Dante configurado en el puerto \$PORT con el usuario '\$USER' y la contraseña '\$PASSWORD'"
```

Guarda y cierra (`Ctrl + O`, `Enter`, luego `Ctrl + X`).

**Paso B: Darle permisos y ejecutar el script:**

```bash
chmod +x /root/dante_bytelixir.sh
bash /root/dante_bytelixir.sh
```
> Sustituye `TU_USUARIO_PROXY` y `TU_CONTRASEÑA_PROXY` dentro del script.

### Preguntas Frecuentes

1. **¿Puedo instalar varias plataformas a la vez?**  
   ¡Sí! Asegúrate de que no usen el mismo puerto o variables que entren en conflicto.

2. **¿Cómo actualizo manualmente los contenedores?**  
   Con Watchtower no hace falta, pero si quieres:
   ```bash
   docker pull NOMBRE_IMAGEN
   docker restart NOMBRE_CONTENEDOR
   ```

3. **¿Qué pasa si quiero cambiar mis credenciales?**  
   - Para la mayoría de contenedores:  
     ```bash
     docker stop <contenedor>
     docker rm <contenedor>
     ```
     Y luego lo **recreas** con las nuevas variables.
