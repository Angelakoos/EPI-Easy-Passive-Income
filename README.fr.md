## Comment l’Installer ?

Voici les étapes les plus simples pour commencer à gagner de l’argent en partageant votre connexion.

> **Remarque Importante** : Lorsque vous louez un VPS (par exemple chez IONOS), accédez au **Panneau de Contrôle** et ouvrez le **firewall** pour **tous les ports** (ou seulement ceux dont vous avez besoin). Étant donné qu’il n’y a rien de critique sur ce serveur, ouvrir tous les ports simplifie la configuration.

### 1. Préparer le Système

Copiez-collez ce bloc de commandes pour :
1. **Mettre à jour et optimiser** le système,  
2. **Installer des paquets de base** (dont `nano` pour l’édition de fichiers),
3. **Installer Docker**,  
4. **Installer Watchtower**,  
5. **Configurer une tâche cron mensuelle** (le 1ᵉʳ du mois à 4h du matin) pour la maintenance,  
6. **Nettoyer** le système.

```bash
echo "[INFO] Mise à jour et optimisation du système..."
apt update && apt upgrade -y
apt install -y curl wget htop ufw git zip unzip nano

echo "[INFO] Installation de Docker..."
apt install -y apt-transport-https ca-certificates software-properties-common
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | apt-key add -
add-apt-repository -y "deb [arch=amd64] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable"
apt update && apt install -y docker-ce
systemctl start docker
systemctl enable docker

echo "[INFO] Installation de Watchtower (mise à jour automatique des conteneurs)..."
docker run -d \
  --name watchtower \
  --restart=always \
  -v /var/run/docker.sock:/var/run/docker.sock \
  containrrr/watchtower \
  --cleanup \
  --revive-stopped \
  --include-stopped \
  --include-restarting \
  --interval 3600 \
  --stop-timeout 30s

echo "[INFO] Configuration d'une tâche cron mensuelle (le 1er du mois à 4h)..."
(crontab -l ; echo "0 4 1 * * apt update && apt upgrade -y && apt install --only-upgrade -y docker-ce && apt update && apt install myst -y && (reboot || sleep 30 && reboot -f)") | sort - | uniq - | crontab -

echo "[INFO] Nettoyage final..."
apt autoremove -y && apt autoclean -y
```

> - **Watchtower** vérifie les mises à jour des conteneurs toutes les heures.  
> - Le **cron** s’exécute le **1er jour de chaque mois à 04:00** (heure du système).  
> - Le VPS redémarre après la mise à jour, restant toujours à jour.

#### 2.9 ByteLixir (Proxy)

[**Cliquez ici pour vous inscrire avec un bonus !**](https://bytelixir.com/r/NPONRRIEOSLD)

- Vous aurez besoin de **Dante** comme proxy SOCKS5.  
- Ensuite, sur le site ByteLixir, ajoutez : `socks5://USER:PASS@PUBLIC_IP:15000`.

**Étape A : Créer un script avec `nano`:**

```bash
nano /root/dante_bytelixir.sh
```

Collez ceci :

```bash
#!/bin/bash
echo "[INFO] Installation de Dante pour ByteLixir..."
apt update && apt install -y dante-server

USER="YOUR_PROXY_USER"
PASSWORD="YOUR_PROXY_PASSWORD"
PORT="15000"
CONFIG_FILE="/etc/danted.conf"

INTERFACE=$(ip route | grep default | awk '{print $5}' | head -n 1)
if [ -z "$INTERFACE" ]; then
    echo "Impossible de détecter l'interface réseau. Veuillez configurer 'external' dans $CONFIG_FILE manuellement."
    exit 1
fi

cat > $CONFIG_FILE <<EOL
logoutput: syslog
user.privileged: root
user.unprivileged: nobody

internal: 0.0.0.0 port=$PORT
external: $INTERFACE

socksmethod: username

client pass {
    from: 0.0.0.0/0 to: 0.0.0.0/0
}

socks pass {
    from: 0.0.0.0/0 to: 0.0.0.0/0
}
EOL

useradd -r -s /bin/false \$USER
echo "\$USER:\$PASSWORD" | chpasswd

mkdir -p /etc/systemd/system/danted.service.d
cat <<EOC > /etc/systemd/system/danted.service.d/delay.conf
[Service]
ExecStartPre=/bin/sleep 10
Restart=always
RestartSec=10
EOC

systemctl daemon-reload
systemctl restart danted
systemctl status danted --no-pager
netstat -tuln | grep \$PORT

echo "[INFO] Dante configuré sur le port \$PORT avec l'utilisateur '\$USER' et le mot de passe '\$PASSWORD'"
```

Enregistrez et fermez (`Ctrl + O`, `Entrée`, puis `Ctrl + X`).

**Étape B : Donner les permissions et exécuter le script :**

```bash
chmod +x /root/dante_bytelixir.sh
bash /root/dante_bytelixir.sh
```
> Remplacez `YOUR_PROXY_USER` et `YOUR_PROXY_PASSWORD` dans le script.

### FAQ

1. **Puis-je installer plusieurs plateformes en même temps ?**  
   Oui ! Assurez-vous seulement qu’elles n’utilisent pas le même port ni des variables en conflit.

2. **Comment mettre à jour manuellement les conteneurs ?**  
   Avec Watchtower, ce n’est pas nécessaire. Mais si vous le souhaitez :
   ```bash
   docker pull NOM_IMAGE
   docker restart NOM_CONTENEUR
   ```

3. **Que faire si je dois changer mes identifiants ?**  
   - Pour la plupart des conteneurs :
     ```bash
     docker stop <conteneur>
     docker rm <conteneur>
     ```
     Et puis vous **recréez** le conteneur avec les nouvelles variables d’environnement.
