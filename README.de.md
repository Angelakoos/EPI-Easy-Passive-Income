# EPI - Easy Passive Income

Willkommen! Hier findest du eine Liste von Anwendungen und Diensten, mit denen du passiv Geld verdienen kannst, indem du deine Internetverbindung teilst. Ich habe jede dieser Plattformen **persönlich getestet** und **empfohlen**, da ich sie **rund um die Uhr (24/7)** nutze.

> **Hinweis**: Es empfiehlt sich, **jede Plattform mindestens einen Monat** lang zu testen, um die Einnahmen genau einschätzen zu können, da diese täglich schwanken können.  
> **Residente (Heim-)IP-Adressen** bringen oft höhere Einnahmen, aber **Rechenzentrums-IP-Adressen** können ebenfalls rentabel sein, lassen sich leicht skalieren und sind dank günstiger VPS-Angebote preiswert.  
> Diese Konfiguration soll **zu 100 % automatisiert und passiv** sein; du musst lediglich gelegentlich deine Einnahmen auf den jeweiligen Plattformen überprüfen.

## Plattformübergreifende Unterstützung

Die meisten dieser Plattformen unterstützen Windows, Mac, Linux, Android usw. Diese Anleitung konzentriert sich jedoch auf **Linux**, da es weniger Ressourcen benötigt und in Verbindung mit einem günstigen VPS sehr rentabel sein kann. Je mehr Geräte du verwendest, desto höher dein potenzieller Verdienst.

## Installation

Hier sind die einfachsten Schritte, um mit dem Teilen deiner Internetverbindung Geld zu verdienen.

> **Wichtiger Hinweis**: Wenn du einen VPS mietest (z. B. bei IONOS), öffne im **Control Panel** die **Firewall** für **alle Ports** (oder nur die benötigten). Da nichts Kritisches auf diesem Server liegt, ist das Öffnen aller Ports für die Konfiguration am simpelsten.

### 1. System vorbereiten

Kopiere und füge diesen Befehlsblock ein, um:
1. **Das System zu aktualisieren und zu optimieren**,  
2. **Basis-Pakete** (inkl. `nano` zum Bearbeiten von Dateien) zu installieren,
3. **Docker zu installieren**,  
4. **Watchtower zu installieren**,
5. **Einen monatlichen Cron-Job** (am 1. des Monats um 4 Uhr) für Wartungsarbeiten einzurichten,  
6. **Das System zu bereinigen**.

```bash
echo "[INFO] System-Update und Optimierung..."
apt update && apt upgrade -y
apt install -y curl wget htop ufw git zip unzip nano

echo "[INFO] Docker wird installiert..."
apt install -y apt-transport-https ca-certificates software-properties-common
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | apt-key add -
add-apt-repository -y "deb [arch=amd64] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable"
apt update && apt install -y docker-ce
systemctl start docker
systemctl enable docker

echo "[INFO] Watchtower (automatische Container-Updates) wird installiert..."
docker run -d \
  --name watchtower \
  --restart=always \
  -v /var/run/docker.sock:/var/run/docker.sock \
  containrrr/watchtower \
  --cleanup \
  --revive-stopped \
  --include-stopped \
  --include-restarting \
  --interval 3600 \
  --stop-timeout 30s

echo "[INFO] Monatlichen Cron-Job (1. des Monats, 4 Uhr) einrichten..."
(crontab -l ; echo "0 4 1 * * apt update && apt upgrade -y && apt install --only-upgrade -y docker-ce && apt update && apt install myst -y && (reboot || sleep 30 && reboot -f)") | sort - | uniq - | crontab -

echo "[INFO] Abschließende Bereinigung..."
apt autoremove -y && apt autoclean -y
```

> - **Watchtower** prüft jede Stunde auf Container-Updates.  
> - Der **Cron-Job** wird am **1. jeden Monats um 04:00** (Systemzeit) ausgeführt.  
> - Der VPS wird nach dem Update neu gestartet, um immer auf dem aktuellen Stand zu bleiben.

#### 2.9 ByteLixir (Proxy)

[**Klicke hier, um dich mit Bonus anzumelden!**](https://bytelixir.com/r/NPONRRIEOSLD)

- Du benötigst **Dante** als SOCKS5-Proxy.  
- Anschließend trägst du `socks5://USER:PASS@PUBLIC_IP:15000` in deinem ByteLixir-Konto ein.

**Schritt A: Skript mit `nano` erstellen:**

```bash
nano /root/dante_bytelixir.sh
```

Füge Folgendes ein:

```bash
#!/bin/bash
echo "[INFO] Dante für ByteLixir wird installiert..."
apt update && apt install -y dante-server

USER="YOUR_PROXY_USER"
PASSWORD="YOUR_PROXY_PASSWORD"
PORT="15000"
CONFIG_FILE="/etc/danted.conf"

INTERFACE=$(ip route | grep default | awk '{print $5}' | head -n 1)
if [ -z "$INTERFACE" ]; then
    echo "Netzwerkschnittstelle konnte nicht erkannt werden. Bitte 'external' manuell in $CONFIG_FILE konfigurieren."
    exit 1
fi

cat > $CONFIG_FILE <<EOL
logoutput: syslog
user.privileged: root
user.unprivileged: nobody

internal: 0.0.0.0 port=$PORT
external: $INTERFACE

socksmethod: username

client pass {
    from: 0.0.0.0/0 to: 0.0.0.0/0
}

socks pass {
    from: 0.0.0.0/0 to: 0.0.0.0/0
}
EOL

useradd -r -s /bin/false \$USER
echo "\$USER:\$PASSWORD" | chpasswd

mkdir -p /etc/systemd/system/danted.service.d
cat <<EOC > /etc/systemd/system/danted.service.d/delay.conf
[Service]
ExecStartPre=/bin/sleep 10
Restart=always
RestartSec=10
EOC

systemctl daemon-reload
systemctl restart danted
systemctl status danted --no-pager
netstat -tuln | grep \$PORT

echo "[INFO] Dante wurde auf Port \$PORT mit Benutzer '\$USER' und Passwort '\$PASSWORD' konfiguriert."
```

Speichere und beende (`Strg + O`, `Enter`, dann `Strg + X`).

**Schritt B: Skript ausführbar machen und ausführen:**

```bash
chmod +x /root/dante_bytelixir.sh
bash /root/dante_bytelixir.sh
```
> Ersetze `YOUR_PROXY_USER` und `YOUR_PROXY_PASSWORD` im Skript.

## Bereit zum Verdienen!

Mit dieser Konfiguration ist dein VPS **automatisiert**:
- **Watchtower** hält die Container auf dem neuesten Stand,  
- **Cron** führt Wartungsaufgaben aus und startet den Server am 1. des Monats um 4 Uhr neu.  

Prüfe einfach in den **Dashboards** der einzelnen Plattformen deine Einnahmen und nimm Auszahlungen vor.

### FAQ

1. **Kann ich mehrere Plattformen gleichzeitig installieren?**  
   Ja! Achte nur darauf, dass keine Ports oder Variablen kollidieren.

2. **Wie aktualisiere ich Container manuell?**  
   Dank Watchtower ist das normalerweise nicht nötig. Möchtest du es dennoch, dann:
   ```bash
   docker pull IMAGE_NAME
   docker restart CONTAINER_NAME
   ```

3. **Was ist, wenn ich meine Anmeldedaten ändern muss?**  
   - Bei den meisten Containern:
     ```bash
     docker stop <container>
     docker rm <container>
     ```
     Danach **erstellst** du den Container mit den neuen Variablen neu.
